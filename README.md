## A/B Test: Landing-page Conversion

A reproducible A/B test of the supplied `ab_data.csv` landing-page experiment. The
requested report filename is retained as `AB_Test_Pricing_Report_CORRECTED.pdf`; however,
the source data contain **no price, revenue, margin or cost fields**. The analysis and
conclusions therefore concern conversion only, not pricing or profitability.

### Result at a glance

After quality controls, the analysis includes **290,584 unique users**. The new-page
treatment converted at **11.881%**, versus **12.039%** for the old-page control:
**−0.158 percentage points** (two-sided two-proportion z-test: **p = 0.1899**;
95% CI: **−0.394 pp to +0.078 pp**). The report recommends **not rolling out the new
page as a conversion improvement** based on this evidence.

| File | What it is |
| --- | --- |
| `ab_data.csv` | Original A/B-test CSV from [`aamir-gk2539-byte/DSML-Training`](https://github.com/aamir-gk2539-byte/DSML-Training/blob/main/ab_data.csv), source commit `94acc3e` |
| `AB_Test_Pricing_Report_CORRECTED.pdf` | Six-page final A/B test report, prepared for Advik Singh (Reg. No. RA2411056030023, DS-A) |
| `AB_Test_Analysis.py` | Reproducible analysis: validation, cleaning, sample-ratio check, z-test, CIs, bootstrap, power/MDE, charts and PDF generation |
| `AB_Test_Analysis_Summary.md` | Concise results and decision summary |
| `ab_test_figures/` | Conversion, cumulative-trend and bootstrap figures generated by the script |

### Reproduce the A/B analysis

```bash
pip install -r requirements.txt
python AB_Test_Analysis.py
```

The script validates the expected schema, removes control/new-page and treatment/old-page
mismatches, retains one (earliest) valid record per repeated user, and regenerates the
PDF, summary and figures. It uses a fixed bootstrap seed (`42`) for repeatable output.
